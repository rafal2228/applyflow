# Dedicated cover letter

Each offer can carry its own cover letter, written on demand and stored **on the
offer itself** — so it travels with the job instead of living only in a generated
file. It is meant to be the practical, send-ready draft: quick to write, easy to
read, hand-editable, and copy-pasteable.

## Where it lives

Open any card to open the **drawer**. Between *Tailored application* and *Notes*
you'll find the **Cover letter** section. Cards that already have a cover letter
show a small **Cover letter** badge.

## What it does

- **Write / Rewrite on demand** — a single button generates a letter tuned to that
  exact company and role, grounded only in `profile/CV.md` + `profile/BRIEF.md`
  (no invented facts). It uses the EN/PL language selected in the drawer.
- **Preview / Edit** — read the finished letter as rendered Markdown, or switch to
  the **Edit** tab to change any wording by hand.
- **Autosave** — edits save automatically ~0.7s after you stop typing, with an
  inline *Saving… / Saved* indicator. A pending edit is flushed when the drawer
  closes.
- **Copy** — copies the full letter text to the clipboard in one click.
- **Tailor prefill** — running **Tailor** also drops the generated cover letter
  into this editor, so the persisted draft and the tailored application stay in
  sync.

## How it's stored

The text is a column on the job row, not a file:

- Table/column: `jobs.cover_letter` (added by a schema migration in
  `lib/db.ts`; the constant `SCHEMA_VERSION` is bumped so cached connections
  re-migrate).
- Exposed on `JobRow.coverLetter` and written via `updateCoverLetter(id, text)`.

Generated by `writeCoverLetter(id, lang)` in `lib/tailor.ts`, which calls the same
OpenAI-compatible LLM client used for grading and tailoring.

## API

| Route | Method | Body | Purpose |
|---|---|---|---|
| `/api/tailor` | `POST` | `{ id, lang, mode: "cover-letter" }` | Generate and persist a letter; returns `{ coverLetter }`. Omit `mode` for the full CV + letter tailor. |
| `/api/jobs/[id]` | `PATCH` | `{ coverLetter }` | Save hand edits (autosave). |

## Notes

- An empty value clears the letter and hides the badge; press **Write** again to
  start fresh.
- Generating requires an LLM endpoint (`OPENAI_*` in `.env.local`); editing,
  previewing and copying never call the network.
